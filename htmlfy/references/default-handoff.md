# 내장 기본 인계·보고 양식

htmlfy·dcfy·lookfy가 다른 에이전트(하위 에이전트)에 일을 맡기거나 결과를 돌려받을 때 쓰는 기본 양식이다.
운영 저장소(설정 `agencyDir`)에 `templates/agent-handoff.md`·`templates/agent-report.md`가 있으면 그것을 우선한다.
위임 구조가 없는 환경(에이전트 혼자 수행)에서는 인계를 생략하고 아래 보고 양식으로 사용자에게 바로 보고한다.

## 인계 (맡길 때)

```
작업 ID: <ID — 프로젝트 규칙이 없으면 짧은 임의 ID, 예 DOC-0001>
목표: <한 줄>
대상 저장소: <경로>   읽을 문서: <AGENTS.md / CLAUDE.md / 관련 docs>
사용자 원문: "<원문>" (<날짜·출처>)
범위·수정 허용 파일: <목록>
완료 조건: <검증 명령과 통과 기준>
보고 양식: 아래 "보고"
```

## 보고 (돌려줄 때)

```
## 핵심 요약
- 된 것 / 안 된 것 / 사용자 할 일·결정

## 상세 내용
- 파일 경로, 문서 URL(허브 또는 file://), 스크린샷 경로
- 검증 명령과 수치(콘솔 오류·외부 요청·가로 넘침 등)
- 커밋 저장소·짧은 SHA·push 여부(했을 때만)
- 확인 못 한 것, 남은 위험
```

## 작업 ID

- 설정 `taskIdPattern`(정규식)이 문서 `meta.taskId` 형식을 정한다. 기본은 영문·숫자·`._-`로 된 아무 ID다.
- 운영 저장소에 티켓 정책(예 `docs/code-ticket-policy.md`)이 있으면 그 규칙으로 발급한다.
